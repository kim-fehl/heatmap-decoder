# M6 — reviewed labelled reconstruction, v0.2.0

M6 connects the existing numerical reconstruction and label implementation.
No calibration, colour matching, sampling or numerical QC algorithm was replaced.
Numeric-only configurations retain headerless matrices and the existing long-form
quality schema. Label sources enable labelled exports and review artifacts.

## Publication and evidence

`extract` and `labels` call the same `extract_labels` implementation. OCR uses
the optional local wrapper/engine, fixed mode and geometry introduced in M4/M5.
Label-bearing extraction first writes `labels.tsv`, `labels_review.tsv`, the
label overlay, and provenance. Every requested slot must have accepted or manual
text before numeric matrix/quality files can be published. Missing, ambiguous
and low-confidence slots return CLI exit **4** with review evidence and no new
matrices. Existing files are protected by `--overwrite`; even when supplied,
unresolved runs preserve older matrix/quality files and record their presence
in blocked provenance. A numeric-only invocation remains explicitly available.

Review TSV import requires exactly `axis`, `index`, `text` and one non-empty
UTF-8 string for each requested slot. Axes are `rows` and `columns`; indices are
zero-based integers. Review rows may be reordered: application is strictly by
index. Wrong headers, counts, missing/duplicate/out-of-range indices, unexpected
axes, malformed quoted TSV and blank text fail before OCR or output writes.
Only outer whitespace is trimmed. Duplicate text remains legal and separately
flagged; neither headers nor rows are deduplicated or renamed.

Manual corrections set final source/status to `manual`. The original raw text,
confidence, boxes, candidates and tokens remain unchanged. Provenance retains
unreviewed assignments separately from final slots and records the exact review
file SHA-256. With an OCR source, reviewed extraction reruns the engine to keep
raw evidence; it still requires the wrapper/engine. Text-file sources are the
alternative when OCR is unavailable. File-label hashes, the image hash, mask hash,
numeric methods/configuration/QC and OCR versions/preprocessing are preserved.

Labelled `matrix.csv` has a `gene` first column and sample header. Labelled
`quality.csv` remains one row per cell with numeric indices/diagnostics plus
`row_label` and `column_label` containing exactly those same strings. Omitted
axes use generated positional labels. Python CSV writers preserve duplicate
names and punctuation, UTF-8, internal spaces, commas and quotes. Some readers
rename duplicate headers automatically; use `csv.reader` when exact duplicates
matter. Duplicate warnings do not merge rows/columns or alter numeric values.

Input figure/configuration/mask/label/review files cannot be overwritten, even
with explicit overwrite. Keep the corrected review file separate from the
destination's `labels_review.tsv` template; the documented `review/` → `results/`
workflow does this naturally. Exit 2 means invalid input, unavailable OCR or I/O
error. Exit 3 retains numerical QC behavior under `--fail-on-qc`; label exit 4
blocks numeric publication first. Neither exit 0 nor high OCR confidence proves
correct biological identity. Values approximate the figure's plotted scale,
not pre-transformation data, and all OCR labels require human verification.

## Complete example

Installation, manual coordinate selection, supported horizontal layouts and
Linux/macOS/Windows engine setup are documented in [README.md](../../README.md).

```bash
uv sync --locked --extra ocr
uv run --extra ocr python examples/labels/workflow.py --out work/v0.2-example
```

This runnable example uses fixed upright gene/sample labels and a separately
generated analytic continuous colourbar with known numeric values. It runs the
label-only command and numeric-only extraction, exports a clean labelled matrix,
blocks an unreadable image, and applies the supplied `reviewed_example.tsv` to
export a correctly ordered matrix with exactly the same reconstructed values.
The unreadable variant degrades only the label ROIs, leaving numerical pixels
unchanged. The review file uses the fixture's known truth; production corrections
must be supplied/verified by a person. Existing output files are not overwritten.

Individual commands:

```bash
heatmap-decoder labels examples/labels/reconstruction.png \
  --config examples/labels/extract_config.json --out review/
heatmap-decoder extract examples/labels/reconstruction.png \
  --config examples/labels/extract_config.json --out clean-results/
heatmap-decoder extract examples/labels/reconstruction_unreadable.png \
  --config examples/labels/extract_config.json --out unresolved/  # expected exit 4
heatmap-decoder extract examples/labels/reconstruction_unreadable.png \
  --config examples/labels/extract_config.json \
  --labels-review examples/labels/reviewed_example.tsv --out reviewed-results/
```

`examples/labels/file_config.json` with `reconstruction.png` is runnable without
OCR and resolves `genes.txt`/`samples.txt` relative to its configuration directory.
`numeric_config.json` extracts the same values without labels. `values.csv` is
the independent analytic numeric truth; `truth.json` describes displayed labels.
The generator and all inputs are included in the source distribution.

## Python library

```python
from pathlib import Path
from heatmap_decoder import ExtractionConfig, UnresolvedLabelsError, extract_file

config_path = Path("examples/labels/extract_config.json")
config = ExtractionConfig.model_validate_json(config_path.read_text())
try:
    result = extract_file(
        "examples/labels/reconstruction.png", config, "results/",
        base_directory=config_path.parent, config_path=config_path,
        labels_review="examples/labels/reviewed_example.tsv",
    )
except UnresolvedLabelsError as error:
    print(error.labels.unresolved_count)  # review artifacts have already been written
else:
    print(result.labels.axes[0].slots[0].final_text, result.values.shape)
```

The file adapter enforces explicit `overwrite=True`. In-memory `extract` accepts
`file_labels` (axis → sequence of strings), `reviewed_labels` ((axis, index) →
string), or a precomputed `label_result` using exactly the same configuration.
It validates fixed slots and raises `UnresolvedLabelsError` carrying evidence
without filesystem exports. CSV writers also enforce the label gate. Numeric-only
calls keep their original arguments and values, with `result.labels=None`.

## Validation and engine environment

Core tests require no OCR wrapper/engine; they use fixed fake responses for
review validation, collisions, one-axis OCR, exact labels/values, duplicate names,
UTF-8/CSV quoting, manual correction of accepted labels, input/output protection,
unresolved gating, file-only sources, missing OCR and numerical mask/QC behavior.
The ordinary cross-platform CI matrix retains Python 3.11–3.14 on Linux/macOS/
Windows. The installed wheel smoke test runs numeric and file-labelled examples
in a fresh environment without the OCR extra, outside the source checkout.

Five opt-in engine-sensitive tests run in a separate Ubuntu 24.04/Python 3.12
job with `tesseract-ocr`, `tesseract-ocr-eng`, and locked pytesseract 0.3.13.
CI logs the actual distribution package versions, available language data and
English traineddata SHA-256. Fixed fixtures/mode/default thresholds are unchanged;
the job includes real clean recovery, unreadable gating, degradation measurements,
reviewed end-to-end reconstruction, and the complete documented CLI example.
Local execution used Tesseract 5.5.0, English data `1:4.1.0-2`, and the traineddata
hash recorded in [M5.md](M5.md); engine-dependent accuracy is separate from
deterministic mocked assertions. No universal OCR accuracy is promised.

```bash
uv sync --locked
uv run pytest -q
uv run ruff check .
uv run mypy src
uv sync --locked --extra ocr
HEATMAP_DECODER_OCR_TESTS=1 uv run --extra ocr pytest -q -s
uv build
uv run python tests/smoke_distribution.py
```

Local results: **143 tests and 18 validation subtests passed with OCR enabled**;
core mode runs **138 tests** and skips the five integration tests. Ruff, strict
mypy, the numeric example and complete v0.2 example passed. Clean and reviewed
labelled values were array-identical to numeric-only reconstruction; the unreadable
run emitted seven unresolved slots without new matrices. Cross-platform and OCR
CI outcomes are tracked by the GitHub workflow for the pushed commit.

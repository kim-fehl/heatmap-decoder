## Implemented scope

See [MIGRATION.md](../../MIGRATION.md) for names and compatibility. `ExtractionConfig`
extends the shared `GridConfig`; both validate optional `LabelsConfig`. Each
axis is either `source: ocr` with an exclusive pixel `bbox`, `source: file` with
a UTF-8 file path, or omitted. Extra/competing source fields fail validation.
OCR settings are `language=eng`, integer `upscale_factor=3` (at least 1),
`min_confidence=80` (0–100), and `max_axis_offset_fraction=0.4` (0–0.5 exclusive
at zero). Confidence is an engine heuristic, never a probability.

`validate_grid_geometry` checks the image bounds for the heatmap and every
requested label region. `crop_label_region` validates before cropping, resizes
with Pillow bicubic interpolation, and returns an explicit reversible
`CropTransform`. `transform_tokens` restores text token boxes to original-image
coordinates without rounding, while preserving text, confidence and line IDs.
Raw adapter tokens remain available to the caller. Non-text structural records
are retained but excluded from grouping and assignment.

Numerical sampling and labels use `axis_slots` from the same grid. Row
assignment uses vertical centres, column assignment horizontal centres; ROI
side does not change order. Only upright horizontal single-line text is supported.

Grouping is deterministic: tokens must overlap vertically by at least half the
smaller height and have a horizontal gap of at most twice the larger height.
Every token must be compatible with every member of its group. A token compatible
with multiple groups remains separate. Engine line IDs are preserved as evidence
and never override geometry. Column words group only inside the same full column
band; a crossing word remains intact. Joining trims only outer whitespace and
inserts one space between words, preserving spelling and internal token spaces.
Candidate confidence is the minimum valid token confidence.

Candidates need a centre within the configured fraction of pitch of exactly one
slot and their complete assignment-axis extent inside its full band. Otherwise,
intersected slots become ambiguous and the candidate is recorded as unmatched.
Collisions are never resolved by confidence. Slots stay fixed; missing entries
do not shift others. Low-confidence text has no final accepted label. Duplicate
accepted strings retain their positions and receive a separate duplicate flag.
Results retain tokens, candidates, membership, boxes, raw text, confidence,
statuses, issues, and unmatched candidate indices. Completely outside candidates
remain available even when they intersect no slot.

## Library example (fake tokens, no OCR engine)

```python
from heatmap_decoder import GridConfig, OCRToken
from heatmap_decoder.labels import labels_from_tokens

config = GridConfig(
    heatmap_bbox=(100, 80, 500, 480), rows=20, columns=20,
    labels={"rows": {"source": "ocr", "bbox": [510, 80, 650, 480]}},
)
result = labels_from_tokens(
    [OCRToken("TP53", (515, 86, 550, 94), 95)], config, "rows"
)
assert result.slots[0].final_text == "TP53"
assert result.slots[1].status == "missing"
assert len(result.slots) == 20
```

Actual OCR, grayscale preprocessing, a `labels` CLI command, TSV/review exports
and label overlays are M5. File/review ingestion, labelled CSVs and strict
publication gating are M6. M4 rejects label-bearing numeric extraction explicitly
(exit 2 in the CLI); omitting label sources retains numeric extraction.

## Validation

Run `uv run pytest -q`, `uv run ruff check .`, `uv run mypy src`, the bundled
numeric example, and the distribution smoke test. Fake-token tests cover all
four ROI sides, fractional shared-grid geometry, transformed boxes, source
validation, image bounds, whitespace/mixed-case spelling, grouping, confidence,
missing and duplicate slots, collisions, spans, offsets and exact half-pitch ties.
They require neither pytesseract nor the Tesseract engine.

Verified in this workspace on Python 3.12: **98 tests and 18 validation subtests
passed**; Ruff and strict mypy passed. The installed `heatmap-decoder` command,
both Python module entry points, and the deprecated executable alias worked.
The source distribution and wheel built successfully, and the isolated installed
wheel smoke test passed. The bundled 20 × 20 example had zero flagged cells;
its matrix CSV, quality CSV and diagnostic PNG were byte-identical to the
unmodified baseline run with the same dependencies. These are local results;
cross-platform CI has not been run for this change.

# M18 — Arbitrary-angle sample-label OCR

**Status: implementation and synthetic supported-scope gates complete.** This is
not publication OCR qualification, a stable release decision or M19 numeric automation.
M17's ordinary-derivative numeric automation limitation remains unchanged.

## Behavior

Finite numeric angles normalize into `[-180,180)` using the visual counter-clockwise
convention. Strings, booleans and non-finite values are rejected. Exact 0/±90°
transposes remain intact for legacy paths. Other angles use an expanded affine
canvas with recorded inverse, padding and bicubic interpolation. Oriented polygons,
baselines, normalized coordinates and matrix-side attachments remain source-linked.

The new line path segments the complete label region before OCR crops, so diagonal
names can cross column bands. Matrix-side endpoint geometry assigns columns using
the M17 resolved intervals. Missing holes, duplicates, conflicting readings and
unmatched headers remain visible. Gene rotation, multiline/mixed-angle names,
light text on dark backgrounds and unseparable overlapping lines are outside the
registered automatic scope.

Automatic proposals measure line/glyph geometry with at most 20 coarse/fine trials,
retain the 180° alternative and use baseline-edge evidence or a declared endpoint
layout assumption to resolve reading direction. OCR confidence never selects an
angle or verifies a name. Weak/uniform-height baselines keep both directions.
Explicit angles override proposals. Shared pixel/call/time budgets and skipped
trials remain auditable. New line identifiers always require review before a
labelled numerical export.

## Validation

One source/runtime/font/model freeze precedes 42 fresh bases and 126 correlated
clean/JPEG/blur attempts. The family includes every required angle plus 37.25°,
above/below text, blocked columns, long names, two fonts and three font sizes.
Selected label/matrix regions and counts are supplied; production primitives never
receive truth strings, polygons or the automatic workflow's reference angle.

| Capability | Clean | JPEG | Blur |
|---|---:|---:|---:|
| Explicit angle: exact ownership/order | 42/42 | 42/42 | 42/42 |
| Automatic directed angle/attachment geometry | 42/42 | 42/42 | 42/42 |

Every accepted association matches original column order, retains the shared grid
hash and lies within the registered source-coordinate attachment tolerance.
Zero wrong accepted associations occur in this partition; all five challenge bases
remain ambiguous/incomplete. A 42/42 base sample has a Wilson 95% interval of about
92–100%; this is not a zero-risk population claim.

Real Tesseract raw spelling is 56/56 in its 14-angle sample. Default RapidOCR is
2/16 in its four-angle sample, with 14 wrong high-heuristic-confidence strings.
**All 72 identifiers remain unreviewed.** No spelling is silently corrected, no
missing identifier is generated and no OCR confidence authorises export.

The automatic validation is an engine-independent geometry ceiling with supplied
regions/counts. End-to-end detection, budgets and flip competition also have
production integration tests and the real CLI example. Whole-figure angle/ROI/count
and publication generalisation are not inferred from this renderer distribution.

## Checks and delivery

Actual focused/full/real-engine checks, Ruff, strict mypy, documented commands,
source/wheel builds and isolated wheel smoke results are in
`benchmarks/m18/checks.json`. Numeric value/flag hashes for the three M17 baseline
workflows remain identical. Reviewed labelled extraction is bitwise identical to
numeric-only output. Existing orientation, ambiguity and numerical regressions pass.

| Path | Scope |
|---|---|
| Explicit arbitrary-angle transforms | Finite angle, column text only; recorded affine/inverse |
| Complete-line association | Dark single-line text, separable lines, selected region, resolved grid |
| Bounded automatic angle proposals | Validated Sans/Mono renderer family; ambiguous flips retained |
| Identifier publication | Complete manual review or supplied label files |
| Arbitrary fonts/dense/light-on-dark labels | Not qualified; review/file-label path |
| Automatic numeric count/scale/export decisions | M19 pending; M17 degradation caveat retained |
| New held-out publication evidence | Not supplied in M18; no publication claim |

# M17 — Block-aware geometry and gap/count detection

**Status: implemented explicit geometry and bounded clean automation; overall
ordinary-derivative automation gate remains incomplete.** No stable-release or
publication-automation claim. M18/M19 are not implemented in this milestone.

## Implementation

One resolved grid supplies numerical sampling, OCR ownership, overlays and exports.
Explicit original-coordinate row/column segments support gaps on either or both
axes, unequal group sizes and unequal explicit segment pitches. Validation rejects
non-finite/boolean bounds, unordered/overlapping/out-of-ROI segments, non-positive
counts, contradictory totals and insufficient inset pixel resolution. Matrix indices
remain global; gaps and segment-local indices are metadata. Numeric and label
provenance share the same grid hash. `grid_diagnostic.png` displays resolved source
intervals, gaps and group indices.

Detection proposes aligned block unions and common-pitch segment counts, including
no-gap alternatives. Evidence retains transverse profiles, measured transitions and
strokes, endpoint and boundary residuals, interior constancy, supported count
alternatives and rejected harmonic models. Supplied counts are assumptions, not
independent evidence. Integer-pitch bands, palette-compatible annotations, broad
boundaries, separator halos, large panel spaces and unresolved full unions require
review. Source sampling for legend association uses the resolved block interiors.
Small/partial blocks cannot be ignored merely because a larger component fits.

Explicit geometry is authoritative. Inferred counts can pass a measured per-image
geometry decision, but remain outside experimental export until M19 qualification.
Identifier spelling still requires review. Existing numerical ambiguity/error/span
protections are unchanged.

## Frozen results and support scope

The final fresh partition contains 40 bases, balanced ten per family, each with
clean/JPEG/blur derivatives, and 12 negatives. All registered cases remain in their
denominators. Scale is supplied/reviewed; ROI, gaps and counts are automatic.

| Family | Explicit clean | Auto clean | Auto JPEG | Auto blur |
|---|---:|---:|---:|---:|
| No gaps | 10/10 | 10/10 | 4/10 | 3/10 |
| Horizontal gaps | 10/10 | 10/10 | 4/10 | 0/10 |
| Vertical gaps | 10/10 | 10/10 | 3/10 | 0/10 |
| Both axes | 10/10 | 10/10 | 3/10 | 0/10 |

All complete accepted cases have finite values, at most 1% flags, MAE below 2%,
maximum error at most 5% of the displayed range, exact dimensions/order and exact
registered source intervals. There are **zero wrong complete decisions** and
**zero negative complete decisions** in this final partition. These finite samples
do not establish zero population risk. The 30/30 clean blocked successes have a
Wilson 95% interval of about 89–100%; each 10/10 family about 72–100%.

Explicit clean and every clean automatic family gate pass. **57/120 (47.5%)** ordinary
attempts complete accurately, below the 70% target. JPEG/blur automation is therefore
incomplete, without retrospective eligibility exclusions. Explicit derivatives can
also abstain on colour ambiguity/flags; none of those protections were weakened.
Earliest blockers: 49 no validated grids, 8 unverified full bounds, 3 broad-boundary
failures, 2 unresolved counts and 1 colour-quality failure. Supplying explicit segments/counts is the useful
manual path, but the exact “one manual field” recovery rate was not separately
measured. This remains a diagnostics/reporting limitation.

All earlier frozen reports are retained. They exposed a partial-matrix acceptance,
then a smaller-component omission and a separator-halo coordinate mismatch. Each
repair used a new source freeze and fresh seeds. The final source is archived. A fourth freeze follows a test-only migration of an
old OCR abstention assertion; production hashes are unchanged from the third freeze.

| Capability | Current path |
|---|---|
| Explicit blocked geometry, including unequal pitch | Supported; user assumption |
| Common-pitch clean aligned blocks, one reviewed shared scale | Measured geometry/count decisions pass synthetic gates |
| Clear no-gap inference | Bounded measured path (at least six cells, ≥95% transitions); existing corroborated path retained |
| JPEG/blur automatic blocked grids | Incomplete; inspect proposals and supply explicit geometry |
| Ambiguous missing/constant bands, annotation strips, independent panels | Review/abstention; alternatives retained |
| Inferred-count automatic numerical export | M19 qualification pending |
| Arbitrary-angle sample OCR | M18 pending; existing 0/±90° paths preserved |
| Automatic OCR scale and independent identifier completion | M19 pending |
| Publication generalisation | Unqualified; existing squid crop is development evidence |

## Verification

The M16 pre-change suite passed 602 tests with 33 skips. New tests assert intervals,
values, dimensions, gaps, contradictory counts, resolution, label ownership/order,
geometry hashes, simultaneous/variable gaps, unequal groups/pitches, constant
neighbours, thin strokes, JPEG/blur and nearby negative cases. Earlier tests that
required blanket abstention on now-supported regular geometry assert correct counts
and decisions instead; omitted-stroke and merged-cell ambiguity regressions remain.

Actual final checks are recorded in `benchmarks/m17/checks.json`: focused M17 tests,
full suite with real OCR enabled, Ruff, strict mypy, all documented example commands,
source/wheel build, existing isolated distribution/OCR smoke, and a separate
installed-wheel blocked extraction outside the source tree. Historical reports and
M16 publication numeric decisions remain unchanged. The publication continues to
abstain automatically and retains partial numeric output with supplied geometry.

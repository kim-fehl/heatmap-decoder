# M16 status

The M16 implementation and acceptance validation are delivered. The current
RapidOCR-default implementation passed a fresh, pre-registered synthetic partition.
Verification passes 635 tests and 18 subtests with real OCR, lint, strict typing,
documentation links, the quick-start example and installed-wheel/CLI checks.
The publication example remains a partial reconstruction with unresolved
source-data provenance; it does not establish full-publication automation or a
stable release.

## Implemented

- Dense observed-gradient inspection, with tick, midpoint and physical-edge
  checkpoints, sampling footprints and colour/contamination evidence.
- Explicit reviewed piecewise-linear numeric calibration, monotonic anchor
  validation, linear comparison diagnostics, coverage reporting and no default
  extrapolation beyond reviewed anchors.
- Bounded OCR, raw alternatives and transform/model provenance. Gene/sample
  recognition defaults to RapidOCR; numeric ticks retain Tesseract constraints
  and auditable sign normalization. Regular slots preserve order and ownership.
- Shared titled ROI and confidence diagnostics, enlarged crops, review ledgers,
  and existing ambiguity/review/export gates.

See the [specification](../specs/spec_6.md), [usage guide](../usage.md) and
[calibration guide](../nonlinear-calibration.md) for behavior and configuration.

## Current acceptance evidence

The [registered validation](../../benchmarks/m16/validation-rapidocr-v1/README.md)
binds source, dependency, model, font and input hashes before evaluation. It has
16 fresh bases and 48 correlated clean/JPEG/blur attempts, plus six edge/ambiguity
negatives. The prior accuracy thresholds were retained, with an additional
pre-registered 80% minimum completion rate.

| Numeric result | Outcome |
|---|---:|
| Complete and accurate | 43/48 |
| Wrong complete numeric exports | 0 |
| Negative numeric exports | 0/6 |
| Worst finite-cell MAE / maximum, normalized by displayed range | 0.514% / 3.587% |

The five ordinary abstentions remain in the denominator. Every attempt records
finite coverage, flags, bound status and runtime; errors on finite cells alone do
not describe an incomplete reconstruction.

| Synthetic label strategy | Raw exact | Accepted exact | False acceptances | Unresolved |
|---|---:|---:|---:|---:|
| Sparse RapidOCR | 512/720 | 512/624 | 112 | 96/720 |
| Per-slot RapidOCR | 672/720 | 592/592 | 0 | 128/720 |

No identifier exports were authorized in either strategy. These small synthetic
labels do not establish biological identity accuracy; the publication below still
has six wrong high-confidence acceptances. Shared renderer/palette/font families
limit generalisation.

## Current publication trial

The [five-workflow report](../../benchmarks/m16/validation-rapidocr-v1/publication.json)
uses the unchanged 33×8 Symbiotic crop from Figure 4 of
[10.1038/s41598-024-53477-3](https://www.nature.com/articles/s41598-024-53477-3).
This is inspected development evidence.

| Workflow | Current result |
|---|---|
| Supplied geometry and reviewed calibration | 251/264 finite cells; partial |
| Automatic ROI with supplied dimensions | Abstains; no export |
| Legend localisation and numeric OCR | 5/5 physical ticks localized and exact; scale still requires review |
| Gene/sample OCR | 26/33 exact genes, 8/8 exact samples; `EsGalectin1` recovered |
| Composed requested workflow | Abstains; no export |

All 41 label slots are retained. Forty pass the heuristic confidence threshold,
but six are wrong; one remains unresolved. Every identifier requires inspection.
The reference-table agreement on 251 finite cells is MAE 0.02228 and maximum
0.18636, or 0.557% and 4.659% of the labelled −2..2 range. The 13 abstentions remain
in the 264-cell denominator. Runtime per workflow is recorded in the report.

## Remaining source-data limits

The TSV's source counts/TPM, log transform, standardisation axis/population,
variance convention and clipping recipe are unestablished; the paper describes
NanoString. Comparisons remain **reconstruction agreement**. The eight displayed
columns are not assumed to be the complete standardisation population.

The physical bar extends beyond its reviewed −2 and +2 ticks. No edge values were
supplied, so unsupported cells remain NaN. One Greek transcription is visually
uncertain, and OCR errors—including dropped spaces in some rotated labels—remain
review evidence. None of these unknowns are filled from the reference table.
